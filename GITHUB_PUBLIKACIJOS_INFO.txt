2. PILNAS KONTEKSTAS — VISKAS KĄ ŽINAU
================================================================
2.1 Projekto istorija
- ZephCore = MeshCore 1.16.7 + Zephyr OS portas (bazė:
  liquidraver/ZephCore GitHub).
- Mes sukūrėme LR2021 Zephyr driverį (DTS + driveris + Kconfig) —
  Zephyr oficialiai LR2021 driverio NETURI; mūsų yra PIRMAS pasaulyje.
- Driveris darytas 1:1 pagal upstream kodus: RadioLib
  (jgromes/RadioLib, src/modules/LR2021) + MeshCore
  (meshcore-dev/MeshCore, RadioLibWrappers.cpp, Dispatcher.cpp).
- Mūsų šaka: lr2021-rx-order-fix (protozauras/ZephCore),
  HEAD f88692c, 14 commit'ų virš master:
  10× LR2021 driveris/RX eilė (RX ilgio skaitymo tvarka, bundle'ai,
  non-blocking TX, „MeshCore kepurė" re-arm 55ms->15ms) +
  4× repeater (LED, stats.daily, 64-bit uptime, login fix).
  git describe: 1.16.7-zephcore-53-gf88692c.
- CI (GitHub Actions) praeina ✅ abiem build'ams (companion + repeater).
- Įrenginys: XIAO nRF54L15 UID 8802F48F, flash per pyocd
  (target nrf54l), serial COM9 @115200.

2.2 Radio konfigūracija (veikianti, patvirtinta)
freq 869.618 MHz · BW 62.5 kHz · SF8 · CR 4/8 · sync 0x12 ·
TX 22 dBm · preamble 32. KOL KAS TIK VIENAS DAŽNIS (perjungimo nėra).

2.3 Testų istorija (2026-08-02)
1. Sandbox testai: 12/12 PASS (tools/lr2021_sim, plain C).
2. Abipusis RX/TX testas: 9/10 (kolizijos — abu siuntė vienu metu).
3. Vienpusis testas kas 3 s: 19/20 (95%) — driver 22/22 paketai švariai.
4. LAUKO TESTAS: signalas nukeliavo 120+ km PER TARPINIUS —
   projektas pavyko.
5. Repeater: pakabintas medyje už kelių šimtų metrų, GAUDA TOLIMUS
   KARTOTUVUS (šis įrodymas — nuotraukose).
6. TX→RX re-arm: 15 ms (buvo 55 ms) — driverio fix'o rezultatas.

2.4 Žinomos problemos (svarbu atpažinti nuotraukose!)
- Admin login per LoRa po reboot NEVEIKIA: app'e tipo
  „password blogas arba nepasiekiamas" / „nejungia admin".
  Per USB CLI veikia. Upstream problema: meshcore-dev/MeshCore
  #983 + #2955 (abi atviros).
- Kartotuvas girdi paketus, bet negali iššifruoti:
  log'e „no peer could decrypt message".
- SNR VISADA 0.0 dB — chip'as grąžina snr=0 (kosmetika, NE klaida).
- Laikrodis po perkrovimo grįžta į 1970 (nėra RTC/GPS) — gali
  matytis laiko klaidos; sprendžiama per meshtimesync.
- Guest login veikia, bet ne visos komandos; admin pirmas bandymas
  gali pasisekti, paskui nebe.
- Elektros sąnaudos: NERAŠYTI publikacijai (matuota pigiu kinišku
  matuokliu, nepatikima).
- Ekranas: neveikia ir nereikalingas (I2C išjungtas).
- Telefono app: MeshCom (versija — reikia patvirtinti iš screenshot'ų).
